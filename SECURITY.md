# Security

Güvenlik sorunlarını herkese açık bir issue içinde paylaşmayın. Depo sahibine GitHub üzerinden özel olarak ulaşın.

API anahtarlarını, erişim tokenlarını veya kimlik bilgilerini bu depoya commit etmeyin. Uygulama anahtarları Windows Credential Manager içinde saklar; yayımlanan paketlere anahtar eklenmemelidir.
